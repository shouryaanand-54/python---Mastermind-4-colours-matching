# Mastermind - 4 Colour Match

A Mastermind-style colour matching game built with Python. The player tries to guess a hidden sequence of four colours, while the program provides feedback on correct colours and positions.

## How It Works

The computer randomly generates a hidden combination of four colours.

The player tries to guess the correct combination. After each guess, the program provides feedback to show how many colours are correct and whether they are in the correct position.

The player continues guessing until they find the correct combination or reach the maximum number of attempts.

## Features

- Random colour combination generation
- Four-colour guessing system
- Feedback for correct colours
- Position matching
- Attempt tracking
- Interactive command-line gameplay
